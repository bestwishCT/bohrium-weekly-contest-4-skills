# 实验方案生成与优化

## 触发与边界

用户要求依据新科学案例生成、改造或迭代可执行实验方案，或同时出现候选版本、有限参数域、预算/排期冲突时触发。核心能力是“目标→可检验设计→三版差异→约束裁剪→有证据修订”。不处理纯文献综述、论文写作或事后数据建模；不声称湿实验、采购、预约、审批或未来响应已发生。危险实验仅作规则允许的设计与分析。

## 实际输入、路径与首次保存

1. 完整读取`/input/case.json`、`/input/task.md`以及case引用的全部原始论文、手册、记录和PDF。以实际`case.output_contract`的字段、嵌套、类型、必填和artifact要求组织输出；本技能示例或脚本格式绝非正式合同。
2. 创建`/app/work`，读`environment/resources.yaml`并实测所用解析器及`python3 -V`；不假定作者机器资源存在。安装根为`/skills/weekly-skill`，其下资源始终用相对路径`references/plan-audit-schema.md`和`scripts/plan_audit.py`引用。
3. 在`/app/work/input-index.json`列全文件、来源版本、读取状态、页/段/表行和未解析对象。尽早把真实`case_id`和合同要求的诚实部分结果写`/app/output/result.json`，后续原地完善；中间表格、脚本输入留在`/app/work`，最终实际结果和合同允许的附件放`/app/output`。
4. 对真实科学来源只作任务所需定位。PDF直接解析实际文件；来源失败记录文件、页段、影响与替代工具，不假定有预抽取答案。

## 生成—比较—验证—修订

1. 将目标拆成可检验假设，逐项写自变量/因变量/控制变量/混杂的操作定义、单位、范围、测量、采样时机和判读。缺样本量或统计依据时列公式与负责人，不补造显著性。
2. 从目标反推科学必要的空白、阳性、阴性或剂量对照，说明各排除何种混杂；无关对照不强加。每步绑定给定型号、量程、精度、附件、材料规格和来源，替代项重新核对安全、成本与排期。
3. **逐份读取实际三个版本化候选**并建立同版证据包：假设、变量、对照、步骤、参数、资源、成本、排期、风险。做版本差异表，列上游事实和对下游影响；不默认最新版最佳，不跨版拼接。按任务指定或“硬约束完整且直接证据最匹配”选基线，记录未选原因和待确认冲突。
4. 先收集设备/材料/安全/历史有效域及case明示离散值、开闭端点、步进、互斥，构造硬可行域。每个建议保留原值、单位、来源、有限域与越界动作。仅在case给定有限域内生成变体；无任务权重时用可行候选并列和取舍，不造最优分。
5. 按实际组数、重复数、单样消耗、给定损耗、数量×单价、机时×费率复算。排期分人工、占机、等待、周转、预约前置和返工缓冲，建立依赖图并算关键路径；缺失价/时长保留公式，严禁按0。超样本/预算/机时/窗口时回到有限域调批量、并行或版本，披露牺牲；无合法解则阻塞。
6. 写污染、无信号、重复性差、样本不足、缺货、设备不可用和越界的触发判据、诊断证据、止损、安全处置、替代路径与转人工点。评审只能给条件性执行状态，安全/伦理/设备/专家事项全部进入确认项。
7. 形成修订记录：`旧ref→新ref、字段、旧/新值、依据定位、原因、受影响步骤/资源/成本/时间/风险、再验证`。运行脚本核验并对受影响项复算；失败则回退至最近通过版本，保留失败结果和复跑命令。

## 确定性复核

先阅读相对资源`references/plan-audit-schema.md`，从实际材料构造`/app/work/plan-audit.json`，再运行：

```bash
python3 /skills/weekly-skill/scripts/plan_audit.py --input /app/work/plan-audit.json --output /app/work/plan-audit-result.json
```

脚本仅使用Python标准库，恰好检查3个版本、有限域成员、来源、成本分币种小计、原报总额、DAG关键路径和预算/窗口；退出0为结构算术通过，2为异常或失败。退出2不能改写为完成。其JSON仅辅助生成正式结果；不要自动把候选域中某值选成“科学最优”。

## 正式输出与判读

严格按实际`output_contract`生成`/app/output/result.json`并含真实`case_id`和全部原字段，不发明顶层键。在合同许可位置交付三类语义：实验方案（含三个版本差异、选定版本、可排期步骤）；依据与风险（来源、算术、验证日志和修订链）；确认项（阻塞与一般建议分开）。按合同保留状态、来源、不确定性和版本变化。材料缺失、无法判断、工具失败分别表述。

合同要求可编辑Office/图示时才生成原文件，并实际渲染PDF/PNG核验；不机械绘图。JSON解析、原字段/类型、必需artifact及预览是交付门禁。正式对比由平台进行，不自制白板、分数或增益。

## 最小非官方示例

虚构输入：3个版本`demo-v1/v2/v3`，参数只允许`1 u`或`2 u`；`demo-v2`耗材`4×2=8 CNY`、机时`20×0.5=10 CNY`、两并行步骤20/30 min，预算30 CNY和60 min。将合成fixture整理为上述schema后调用上条命令。示意输出（非正式案例结果）：`demo-v2`成本18 CNY、关键路径30 min；仅表示复算通过，不是设备档期、报价或实验结论。
