# 实验参数优化建议

## 触发与不适用

用户要求在真实设备/材料/安全边界内优化实验参数、平衡响应—成本—通量，或处理候选越界、无可行域、搜索停止时触发。不是纯建模展示或经验清单，不用于实际危险设备操作；不声称新测量、未来响应、设备状态、统计显著性、收敛或批准。

## 读取真实任务与保存

1. 完整读取`/input/case.json`、`/input/task.md`及所有来源、设备手册、材料规格、安全阈值、历史数据和三版方案。读取真实PDF而非文件名标签；在台账中给文件页/表/行和版本。
2. 以`case.output_contract`原字段、类型、层级、单位表达、必填、附件及必需验证为唯一正式输出依据。`/app/output/result.json`含真实`case_id`及全部原字段，本技能schema不是官方合同。
3. 工作文件放`/app/work`，最终真实结果与合同附件放`/app/output`，尽早保存诚实的部分结果。安装根`/skills/weekly-skill`，资源使用相对路径`references/bounded-search-schema.md`、`scripts/bounded_search.py`。
4. 阅读`environment/resources.yaml`并实测工具版本。区分原始事实、明示换算、确定计算、历史响应、模型预测、假设和待确认；前瞻资源/价格/预约不是现实库存/报价/档期。

## 有界搜索专属流程

1. 分固定量、决策变量、响应和混杂控制；每值留原始单位、来源和适用版本。实际**三个版本化候选**分别建立参数域、基线和变更表；按任务指定版本优化，不取各版有利部分拼成新版。
2. 先求硬可行域：设备量程/精度、材料耐受、安全阈值、历史有效域、case有限值/端点/步进、互斥与联动。先单位核对再约束检查；没有明示换算就保留冲突。硬约束不因追求响应放松；空域列冲突双方和可合法调整的软条件，无“最优”。
3. 响应定义科学含义、单位、测量、方向、波动与验证。严格区分历史观察、实际运行结果、预测与目标；数据不足只给合规初始点和采集方案。确需代理模型时用实际数据记录特征、版本、训练/验证划分、方法和真实不确定度，不外推保证。
4. 域规模按`Π|离散值|`算；不超过设定上限用确定性枚举，规模大时保留分阶段/序贯候选和覆盖理由。初始点须来自基线或域内可解释覆盖，不越界。选择网格、序贯或经验证的贝叶斯工具时说明理由、每批补点、已有响应使用方式，不把建议轮次写成已实验。
5. 成本复算固定项、重复×每次消耗、参数相关有来源成本、机时、人工、耗材、等待和返工；币种与单位不混加。任务给权重/目标损失才使用；未给时用硬过滤、Pareto并列或任务明示的优先级，不造精确综合分。
6. 对保留、拒绝与推荐均写理由。给推荐值、允许区间、单位、设备材料约束和验证步骤；有限域内确有备选才给备选及代价。停止只能基于预算/通量耗尽、合同轮次、可行候选验证完成、空域或明示目标/无改进规则；无新数据严禁声称收敛。
7. 补全假设变量、匹配对照、设备材料、步骤和判读。设备报错、指标矛盾、数据缺失、越界或重复性差分别给触发、暂停止损、诊断和转人工。算数可行不等于安全伦理或专家批准。

## 确定性枚举、成本与判读

阅读相对文件`references/bounded-search-schema.md`后，在`/app/work/bounded-search.json`按实际材料构造辅助输入并运行：

```bash
python3 /skills/weekly-skill/scripts/bounded_search.py --input /app/work/bounded-search.json --output /app/work/bounded-search-result.json
```

标准库脚本按三版独立枚举，验证基线成员/单位、线性组合、预算和时间，保留成本/分钟算式，按给定响应求成本—时间—响应Pareto集、取舍差及下一批。退出0只表示这些确定性检查完成；退出2表示失败或版本无可行域，输出仍保留。不把Pareto等价于科学最优，不自动填充响应或由模型补值。行业非线性/安全约束未被输入表达时，不能宣称全约束已验证。

## 正式输出与恢复

按`output_contract`容纳关键参数/区间、响应口径、搜索批次、对照、设备材料、时间成本、判读；来源、候选筛选、每轮真实状态、成本和停止；确认项与风险。保留版本变更、状态、来源、不确定性及未搜索空间，不新增顶层键。价格/预约/数据缺失给公式和受阻范围；计算失败保留错误、部分候选和重跑命令，修复后重跑而非改成通过。

合同要求可编辑Office/图示时才交付实际源文件及由它渲染的PDF/PNG。检查JSON、原字段/类型、artifact和预览，不机械绘图或写综述。

## 最小非官方示例

虚构v1参数a、b均在`{1,2}`（各自单位uA/uB），约束`a+b≤3`，固定成本1 CNY、2重复×1 CNY，参数成本`0.1a+0.05b`，准备5 min+2×10 min，预算20 CNY/时间30 min。点(a=1,b=1)算得`1+2×1+0.1×1+0.05×1=3.15 CNY`和25 min；只使用fixture提供的演示响应。示意输出（非正式案例结果）：3个域内点、成本3.15 CNY；“已提供评估已检查、非收敛”，不是湿实验结果或真实报价。
